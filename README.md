# ウロペディア

公開サイト: https://c86tori.github.io/uro/

記事とドット絵画像からなる静的サイトです。

`site-part-01.zip` から `site-part-07.zip` が公開用ファイル一式です。GitHub Actions が全パッケージの SHA-256 とページ数を確認して展開し、GitHub Pages へ公開します。ZIP はダウンロード用の閲覧ページではなく、配信ファイルの保存形式です。

更新時はパッケージと `.github/workflows/pages.yml` の照合値を合わせて更新してください。元の制作履歴、音源、非公開動画、認証情報は含みません。
